# 播放功能实施计划

更新：2026-09-17。状态：阶段 1、2 已实现；阶段 2 交互待手动验收，阶段 3–5 待开发。

## 目标与实现方式

先让搜索到的歌曲可靠播放，再逐步补齐完整播放页、队列、恢复和歌词。继续使用 `feature/search-playback` 分支，每阶段单独验证、交付，避免一次铺开全部功能。

基于现有 Media3 服务自行实现播放核心；NeriPlayer 用于参考布局和交互，边界清晰、适配成本低的组件可按需复用。暂不整体迁入上游播放架构。实际复制或改写上游代码时，保留版权声明并更新 `THIRD_PARTY.md`。

## 分阶段完成清单

| 阶段 | 实现内容 | 完成标准 |
| --- | --- | --- |
| 1：点歌出声 | 核对 `/song/url` 真实响应；接入当前会话与 MediaController；点击搜索歌曲播放；底部迷你播放器显示封面、歌名、歌手、播放/暂停；接通后台、通知栏和锁屏控制 | 可播放有权限的歌曲，暂停/继续状态一致，切后台不中断；加载、失败、试听和无权限可区分；退出或切换账号/服务地址停止播放并清除状态 |
| 2：完整播放页 | 点击迷你播放器进入；大封面、完整标题和歌手、进度与时间、拖动定位；提供返回入口 | 页面与迷你播放器、系统媒体控制状态一致；长文本可读；返回不打断播放 |
| 3：队列与切歌 | 普通队列、上一首/下一首、队列查看/点选/移除；顺序、随机、单曲循环；搜索结果菜单支持下一首播放 | 切歌和播放模式符合预期；空队列、移除当前歌曲有明确行为；后续搜索不改动已有队列 |
| 4：恢复与稳定性 | 保存队列、当前歌曲和进度；重启恢复为暂停；按需重新解析过期地址，限制自动重试 | 重启不自动出声；失效链接可恢复或明确报错；断网不无限重试或无限跳歌；旧账号请求不能回写 |
| 5：基础歌词 | 实测歌词搜索与下载，后台解码 LRC；播放页查看歌词、滚动高亮、点击跳转 | 时间轴跟随播放和拖动；无歌词、加载及失败有真实提示 |

阶段 1 已接通单曲点播、迷你播放器与 Media3 系统控制；阶段 2 已接入完整播放页和拖动定位，阶段 3–5 尚未实现。

## 交互约定与待确认项

- 界面采用 Material 3，以封面和留白为主；文字允许换行，不用固定高度挤掉歌手信息。没有当前歌曲时不显示迷你播放器。
- 当前保持单曲点播，新点选歌曲替换当前单曲；点击迷你播放器打开完整播放页，暂停和重试按钮仍可直接操作。
- 阶段 3 的搜索点播队列规则待确认：建议将当前已加载的歌曲结果作为队列，从点击位置开始；不自动加载全部搜索分页。也可改为仅加入点击的歌曲。此建议尚未被用户确认，不阻塞阶段 1。
- 阶段 3 实施时明确队尾停止、移除当前歌曲及重复歌曲的处理规则，并写入验收说明。
- 完整播放、试听和不可播放按真实响应与账号权限判断，不猜测试听长度，不绕过权限。基础错误提示从阶段 1 就实现，不推迟到稳定性阶段。

## 技术边界

- UI 通过 ViewModel/StateFlow 展示状态，通过 MediaController 操作；ExoPlayer 由 MediaSessionService 唯一持有。云端账号业务与播放状态分开管理。
- 播放时解析 URL，持久化只保存歌曲标识、队列和进度，不保存可复用的临时播放凭据。不向音频 CDN 发送 API Cookie/Authorization。
- 请求、歌词解码和持久化不阻塞主线程；快速点选时取消或忽略旧请求。退出、账号切换和服务地址变化时清除关联播放状态。
- 沿用音频焦点与耳机断开处理，并实际验证后台服务生命周期。基础播放先使用实测可用音质。
- 暂用开发 API 联调；本计划不代表已完成 Kotlin 直连。

## 验证与交付

每阶段只补与行为有关的关键测试；网络适配使用脱敏字段结构或 MockWebServer，不在自动化测试中使用真实账号。运行 `assembleDebug / testDebugUnitTest / lintDebug`，再做一次针对性模拟器检查，不反复扩大调试范围。

用户手动验收真实听感、锁屏/后台、耳机拔出、音频焦点和网络异常；按阶段提供简短操作清单。如实记录尚未验证的场景。每阶段更新本文状态与 README，说明已完成、验证结果和剩余工作。

## 本轮不包含

喜欢和加入云端歌单随音乐库阶段接入；音质选择随权限与格式验证接入。评论、FM、下载、KRC 逐字歌词、复杂动效和完整歌手/专辑主页不放进本轮。它们与整体 v0.1 的关系仍以 `V0.1.md` 为准。

## 阶段 1 实现与验收记录（2026-09-17）

- 数据层：`AudioSourceResolver` 定义歌曲到临时音频源的边界，酷狗实现负责请求与响应解析；先请求完整音频，确认权限拒绝后才请求官方支持的试听。未识别响应明确报错。
- 服务层：`PlaybackRequests` 取消旧请求并校验请求版本；`PlaybackService` 持有播放器及解析任务。`PlaybackSessions` 监听加密会话与服务地址变化，独立于 Activity；退出或切换账号会取消解析、停止并清空播放。
- 界面层：`PlaybackViewModel` 仅连接 MediaController；搜索通过歌曲回调点播，迷你播放器展示真实加载、缓冲、试听与失败状态。失败后用户点击重试会重新解析地址。没有完整播放页或队列菜单。
- 会话变更通知仅含版本号，不包含凭据。播放与图片请求不复用 API 客户端；音频 URL 不写入持久存储、界面诊断或日志。系统媒体控制仅接受应用自身与受信任控制器，不开放任意 URI 注入。
- 实测普通请求的权限拒绝样本为 `status=2`、`priv_status=0`，并有 `fail_process=[pkg,buy]`；开启服务支持的 `free_part` 后返回 `status=1`、`url` 数组和 `hash_offset.clip_hash/start_ms/end_ms`。样本整曲 `timeLength=324` 秒，但允许试听范围为 0–60000 毫秒；播放器额外限制为该范围，通知栏标题标记“试听”。
- 当前只接入已核对的零起点试听格式。非零起点试听、未知权限结构或缺少试听边界不会按完整歌曲播放；后续拿到对应播放响应再扩展。开发核对样本以权限拒绝和试听为主；用户随后手动确认会员歌曲显示试听、非会员歌曲正常播放。
- 自动化测试使用合成数据与 MockWebServer，覆盖播放响应、网络请求、试听边界、快速切歌和账号失效后的迟到响应；不使用真实账号。构建、41 项单元测试和 lint 通过，临时字段核对入口已删除。

用户手动验收清单：

1. 搜索并点击一首歌，检查封面、标题、歌手、试听提示以及暂停/继续。
2. 快速点选不同歌曲，确认最终只播放最后一首；切换搜索分类不替换当前歌曲。
3. 切后台、锁屏，从系统媒体控件暂停/继续；真机拔耳机、来电或其他应用抢占音频焦点。
4. 断网点歌，检查错误与重试；退出账号或切换服务地址，确认音频停止且迷你播放器清除。
5. 使用有完整播放权限的歌曲验证完整播放；试听歌曲应在允许范围结束，不继续播放其余部分。

本阶段不恢复进程终止前的歌曲，不自动刷新过期链接；用户可手动重试。耳机/音频焦点、真实听感和其他机型需用户验收。

用户验收反馈：2026-09-17，点击歌曲可以听，会员歌曲正常显示试听，非会员歌曲正常播放。阶段 1 核心点播已确认；后台/锁屏控制、耳机和音频焦点、退出清理仍保留在手动验收清单。临时中文输入辅助入口已从源码删除。

## 阶段 2 实现与验收记录（2026-09-17）

- 点击迷你播放器进入完整播放页，展示大封面、完整歌名与歌手、试听标签、加载/缓冲/错误状态和播放/暂停或重试按钮。顶部返回与系统返回均回到原导航页，不停止播放。
- 完整页与迷你播放器共用 PlaybackViewModel 和 MediaController。界面订阅期间每 500 毫秒读取实际进度，播放器事件立即同步暂停、切歌与系统控制状态；没有界面订阅时停止轮询。
- 总时长取播放器实际媒体时间轴，不使用搜索结果整曲时长代替试听范围。未知时长显示 `--:--`；尚未解析、不可定位或失败时禁用拖动。拖动时预览目标时间，松手后定位，校验当前歌曲并限制到实际时长范围。
- 页面可滚动，长文本允许换行，封面限制最大宽度；提供浅色和深色大字体 Preview。播放页可见状态随界面重建保存；会话清空后回到主界面。未新增队列、上下首、喜欢或歌词入口。
- JDK 17 下 `assembleDebug / testDebugUnitTest / lintDebug` 通过，现有 41 项单元测试通过；lint 无错误，仍有依赖版本、媒体服务导出、备份规则和未使用资源提示。本次未新增网络协议或调用真实账号写接口。
- 最终调试包已安装到在线模拟器，启动检查正常；当前没有播放歌曲，尚未实测完整页、拖动与系统控制同步。Preview 已编译，未做渲染验收。

手动验收：

1. 搜索并播放歌曲，点击迷你播放器的封面或文字进入完整页；检查完整歌名、歌手、大封面及暂停/继续。
2. 播放时观察进度前进；拖到中间并松手，确认跳转。暂停时拖动应保持暂停。试听歌曲的总时长与拖动范围不能超过允许范围。
3. 使用顶部返回和系统返回，确认回到此前导航页且播放不中断；迷你播放器暂停按钮应只暂停，不打开完整页。
4. 在完整页切后台、锁屏并用系统媒体控件暂停/继续，回到页面核对状态与进度。
5. 检查屏幕旋转、深色模式、1.5 倍字体、长标题/多歌手和横屏滚动；控件应可达、文字不被截断。
6. 断网点歌或重试，确认错误提示且进度不可拖动；退出账号或切换服务地址后确认旧播放内容清空。
