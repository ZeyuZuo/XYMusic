# FM 阶段 2：播放与有限续播

2026-09-26。代码和自动化验证已完成；真实连续播放、后台及设备恢复待人工验收。本文件记录阶段 2 基线；后续显式“不喜欢”已实现待验收，自动播放反馈仍未接入，见 [阶段 3 说明](FM_FEEDBACK.md)。

## 职责与行为

- `data/recommendation/FmRepository.kt`：复用账号会话，调用 POST `/personal/fm` 并绕过中转缓存，只映射公开歌曲元数据。请求固定 `action=play`、`platform=android`、布尔 `is_overplay=false`，remaining 仅 0–2；不携带歌曲 hash、songid、playtime 或 garbage 反馈。
- `playback/FmCoordinator.kt`：由播放服务持有，管理单个请求、请求代次、有限去重窗口及补充状态；不依赖首页是否可见，不持有另一个播放器。`PlaybackService` 继续独占 ExoPlayer，负责音频解析、试听、媒体键、停止和恢复。
- 首页“猜你喜欢”首次点击启动，首批成功才替换普通队列并打开完整播放页。连续点击不会重复启动；失败或空批次保留原队列。已有 FM 时只打开播放页，暂停保持暂停。
- 排除当前项后的待播数降至 2 时补歌；单次最多将自动推荐待播量补到 10。自动推荐按大小写无关 hash 排除同批、当前、待播和最近 50 次播放窗口中的重复。用户主动点播/插入允许重复，不受自动推荐去重影响。
- 小首批首次只发一次请求，不立即追发补歌。空结果、全重复及错误会锁住自动重试；已有内容可继续播放，手动“重试获取推荐”才重新请求。播完无后继时暂停；迟到补歌只加入待播，不能自行重新出声，点击播放继续。
- FM 固定顺序播放，队列保留当前项、最近最多 20 条历史及待播内容；不保存进入 FM 前的普通列表。自动推荐不会无限增长；用户主动插入的待播歌曲不会被数量上限悄悄丢弃。
- FM 隐藏并在服务层拒绝清空、随机和单曲循环。可点选/移除条目，但无后继时不能删除当前项使 FM 成为空会话。搜索点播和下一首插入保留 FM；日推整表替换退出 FM。
- 停止、账号变化及普通列表替换使请求代次失效并取消任务，迟到数据不得修改队列。播放地址解析失败或权限不足沿用现有失败状态，不自动连续跳过歌曲。
- 复用原子播放快照，保留类型、entryId、当前项和进度。重启只恢复暂停，不拉推荐、不发反馈；用户继续播放后重新解析音频并恢复补歌。最近 50 次去重窗口仅在进程内，不持久化完整听歌历史。

## 实测接口证据

用户额外授权三次只读请求：首批 `remain_songcnt=0`、补充 `remain_songcnt=2`、一次歌曲搜索。两批 `status=1/error_code=0`，各 5 首，本次两批无相同 hash；这不保证所有后续批次都不重复。

同 hash 的 FM `time_length=232` 与搜索 `Duration=232` 一致，客户端按秒转毫秒。两批 10 首均在 `relate_goods` 中找到唯一大小写无关 hash 匹配且 album_id 一致的变体；变体 `album_audio_id` 为数字，albumname 和 info.image 为字符串，图片含 `{size}`。只有唯一匹配才补齐播放 ID、专辑和封面；不拿第一个变体，不把 songid 或 mixsongid 冒充播放 ID。songid 仅作为来源 ID 保存。

本次未调用播放地址、garbage 或歌曲反馈；原始响应、凭据及真实歌曲标识没有保存。临时本机服务、端口转发、测试包与源码已清理。未修改上游仓库。

## 验证与人工复测

规定构建、单元测试及 lint 通过，95 项单元测试（新增 15 项）：协议和请求白名单、变体精确匹配、单请求启动、小首批、并发补歌、大小写去重、用户重复插入、空/重复/失败停止重试、停止/退出后的非协作迟到结果、恢复不拉取、待播/历史窗口上限。全部使用合成响应/假仓库，不访问真实账号。

最终调试包已安装到模拟器，启动与首页结构检查通过：猜你喜欢入口可点击，显示“开始播放为你推荐的歌曲”。本次没有额外自动操作真实 FM 播放，首页检查不代表前后台续播验收通过。

请在开发服务可用、已登录时按顺序复测：

1. 普通歌曲正在播放时点击“猜你喜欢”：只在首批成功后切到 FM；快速连续点击应只启动一次。首批失败时原播放应保持，可再点击重试。
2. FM 连续播放至少 8 首，观察待播数在低位时补充；尝试通知栏/锁屏下一首，确认与页面一致。试听片段结束可以推进，但不标记完整歌曲已听完。
3. 暂停后返回首页再点 FM，应仍暂停。搜索点歌及“下一首播放”均保持 FM，允许重复；日推点歌则整表替换并退出 FM。
4. FM 中断网，已有歌曲和队列应保留；补歌失败不反复请求、不连续跳歌。恢复网络手动重试；批次耗尽时停住，补齐后点击播放继续。
5. 补歌过程中点播日推、退出账号或用系统媒体停止，迟到结果不得覆盖新队列或自动出声。FM 队列没有清空和模式菜单。
6. 强制停止后重开，应恢复 FM 类型、条目和进度但保持暂停；仅打开首页/FM 页不拉取，点击播放才重新解析和补歌。
7. 检查深色、大字体、封面及歌词切歌。真实后台续播、音频焦点/耳机和账号切换均仍待人工确认。

完成这些验收后，再单独核实反馈时长单位、成功码、试听/完整播放语义，进入阶段 3。不能把推荐请求成功当作反馈已接通。
